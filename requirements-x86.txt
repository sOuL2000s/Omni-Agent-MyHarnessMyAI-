# Runtime dependencies for the 32-bit Windows build.
#
# lancedb and openai are excluded because their native dependencies do not
# build for i686-pc-windows-msvc:
#   * lancedb -> gearhash -> uses _mm256_insert_epi64 / _mm256_extract_epi64,
#     AVX2 intrinsics that do not exist on 32-bit x86 targets.
#   * openai -> pyarrow -> its CMake setup explicitly refuses 32-bit Windows.
# The agent's vector memory gracefully degrades (HAS_VECTOR=False); SQLite
# facts and keyword search still work because they use the standard library.
#
# Everything else below installs from a pure-Python wheel on 32-bit Windows
# and is present in the 9.0.0 x86 build. Do not remove selenium /
# webdriver-manager without updating the release notes: dropping them
# silently downgrades AGENT_BROWSER=selenium to a no-op.
